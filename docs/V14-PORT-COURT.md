# v14 port: Court of Ravenloft (Nix Fix 1.7.0)

Status: **steps 1-6 written and offline-checked, not table-tested** (2026-11-10). Ships in Nix Fix 1.7.0 with the v13 1.6.1 work. Sources checked: Nix Fix 1.6.0 (f380e83), Chris's Premades 2 main (ff957bb), Chris's Premades 1.5.51 (tag), CAT main (72ca2c1, github.com/chrisk123999/covens-automation-toolkit), dnd5e 6.0.6 (tag release-6.0.6). v14 exports: Dracula, Petra (Updated), Dayus Manroe, Sydmore, Valintina, Lucian (Foundry 14.369, dnd5e 6.0.6, after the Medkit), copied to `FoundryVTT Fixes/exports/v14/`.

## What the exports show
- None of the six has any Nix Fix macro or flag. The v14 installers build from scratch on these sheets.
- No "(Boss)" copies in the set, and no Juggernaut. Dracula still has the Blood Moon Blade (no Bloodrift yet).
- **Chris's Premades 2 has no Illrigger automations.** The Illrigger features still carry their v13 identifiers (`flags.chris-premades.info.identifier`: balefulInterdict, infernalConduit, interdictBoon*, deathstrike, devastator, youDieOnMyCommand, masterOfHell...). Those are inert on v14 but readable, so our name/identifier lookups still find the items.
- Petra: Chris's Premades 2 now automates **Wall of Death** (`wall-of-death`) and **Prismatic Wall** (`prismatic-wall`), Strength of the Grave (`preventDeath` generic), Teleport, the Summon spells. Innate Sorcery and Lucky are Midi automation notes. Metamagic items still carry v13 identifiers (inert).

## Why this isn't a straight port
1. **The runtime mostly survives.** `scripts/court/*.mjs` hook `midi-qol.premades.*`, `dnd5e.*` and core document hooks. CAT itself listens to the same Midi hooks on v14 (`cat/scripts/lib/constants.mjs` workflowHookNames), so they still fire. What breaks: the Chris's Premades 1 helpers (`cpr()` = `chrisPremades.utils`), effect data (`mode`, `duration: {seconds|turns}`), `chrisPremades.Teleport`, and Petra's templates (Regions on v14).
2. **The big gap: the Court leaned on Chris's Premades 1's Illrigger automations, which don't exist on v14.** Behaviour we used without writing it: Infernal Majesty (+ its `infernalMajestyEffect`), Infernal Conduit (Devour heals him, `activityIdentifiers`, hidden Invigorate), Terrorizing Force, Combat Mastery: Inexorable / Unfettered / Bravado / Lies, Interdict Boons (Bedevil, Styx's Apathy, Unleash Hell, Soul's Doom item, Flash of Brimstone, Hellish Frenzy, Hellsight, Impaling / Vengeful Shot, Dis's Onslaught, Conflagrant Channel), Painkiller (Telekinetic Seal, By the Throat, Dispater's Supremacy, Grand Strategist, Punishment, Deathstrike, You Die on My Command!, Devastator, Dispater's Blessing), Master of Hell, Superior Interdict, Forked Tongue. The Dracula boss kit also pulls items from the CPR1 compendium `chris-premades.CPRThirdPartyClassFeatures`, which isn't in Chris's Premades 2.
   - Chris's Premades 1.5.51 has all of these: `scripts/macros/2014/classFeatures/illrigger/` (1,959 lines, MIT licence). They port to CAT the same way our other macros did (V14-MAPPING.md sections 2-5).

## Plan
**Step 1. Engine adapter** (`scripts/court/engine.mjs`). On v13 `cpr()` stays `chrisPremades.utils`. On v14 it returns an object with the same helper names the Court calls, routed to `cat.utils` with placeable -> TokenDocument conversion: `workflowUtils.syntheticItemRoll / syntheticItemDataRoll / syntheticActivityRoll / syntheticActivityDataRoll / bonusDamage / bonusAttack / modifyDamageAppliedFlat / applyDamage / isAttackType`, `tokenUtils.getDistance / findNearby / canSee`, `actorUtils.typeOrRace / checkTrait / hasUsedReaction / setReactionUsed / getFirstToken`, `dialogUtils.confirm / buttonDialog / selectTargetDialog`, `socketUtils.firstOwner` (-> `queryUtils.firstOwner`), `genericUtils.setFlag / update`, `effectUtils.getEffectByIdentifier`. Gaps to write ourselves: `rollUtils.makeCritical` (set the d20's `criticalSuccess` to its result), `itemUtils.canUse`, `chrisPremades.Teleport.target` (CAT `tokenUtils.teleportToken`). Plus `fx(data)`: converts our effect data to v14 (`system.changes` with `type`, `duration: {value, units}`, `flags.cat.identifier`). Each runtime file swaps its `const cpr = ...` line for the import; effect writes go through `fx`.
**Step 2. Illrigger class features on CAT** (`scripts/court/illrigger-features.mjs` + world installer v14 copy), ported from CPR1's illrigger folder, only the features the Court sheets actually have. Identifiers kept (`flags.cat.identifier` = the CPR1 name) so the existing lookups keep working. Activity/embedded macros through CAT `flags.cat.embeddedMacros`.
**Step 3. Dracula** (final battle): boss kit + Bloodrift v14 copies. The CPR1 compendium pull becomes "build the item ourselves" (step 2 provides the macros).
**Step 4. Petra** (final battle): Sorcerer core + Petra fixes v14 copies (2024 Metamagic on CAT passes, reusing Bangiras's v14 Quickened / Heightened / Twinned and Akira's v14 Extended). Petra spells: decide Wall of Death / Prismatic Wall vs Chris's Premades 2's own (read `chris-premades/scripts/macros/all/spells/wallOfDeath.mjs`, `prismaticWall.mjs`); Negative Energy Flood, Finger of Death, Sorcerous Burst stay ours.
**Step 5. Lieutenants** (Dayus, Sydmore, Valintina, Lucian): fixes + boss v14 copies, `tools/court-boss-build` gets a v14 target.
**Step 6.** Registry `v14:` entries, main.mjs gate (opened for the engine, Bloodrift and the boss kit in step 3; lieutenants and Petra's spells to follow), offline check on each installer against the exports, CHANGELOG, version 1.7.0.
