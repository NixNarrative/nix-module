# Moving the automations to Foundry v14
 
Status: **Bangiras pilot, world installers, The Fool's Journey and Journey to the East written, not table-tested.** Mapping report: `docs/V14-MAPPING.md`. Notes and test checklists: `docs/V14-PILOT-BANGIRAS.md`, `docs/V14-PORT-WORLD.md`, `docs/V14-PORT-FOOLS-JOURNEY.md`, `docs/V14-PORT-JOURNEY-EAST.md`. On a v14 world Nix Fix runs only automations that have a v14 copy; the rest show "Not ported to v14 yet", and the ones Chris's Premades 2 does itself show "Retired on v14".
 
## What changes (checked against the sources, Nov 2026)
- Chris's Premades 2.x targets Foundry 14 / dnd5e 6 only, and requires **Coven's Automation Toolkit (CAT)**, Midi QOL 14.6.5+ and DAE 14.6.4+. Chris's Premades 1.5.x stays on v13. Midi 14.6.x supports dnd5e 6.0.x only (not 6.1).
- Embedded macros moved from `flags.chris-premades.embeddedMacros` to `flags.cat.embeddedMacros`. Stored entries are `{name, event, pass, macros: [{macro, priority}]}` (the Medkit shows them flat). Activity macros go on the activity itself: `activity.flags.cat.embeddedMacros`. Passes carry a scope prefix (`itemRollFinished`, `actorDamageRollBonuses`, `targetDamageComplete`...). Full table in V14-MAPPING.md.
- Macro scope: no `trigger` variable; its fields are spread in (`document`, `workflow`, `ditem`, `config`, `options`, `roll`...). `token` is a TokenDocument. CAT utils are injected; several of ours were renamed or removed (`socketUtils.firstOwner` -> `queryUtils.firstOwner`, `rollUtils.remoteRoll` and `combatUtils.inCombat` gone, `effectUtils.createEffect` -> `createEffects`).
- Foundry 14 effects: `system.changes` with `type` (not `mode`), durations `{value, units, expiry}`. DAE converts `ATL.*` keys to `token.*` (not `ATL.texture.src`). Templates are Regions.
- Chris's Premades 2.1.x: items need their automation re-applied after migrating; effects use native expiry instead of DAE special durations. **Re-applying an item in the Medkit wipes `flags.chris-premades` on it**, so the v14 installers reinstall from their own files.
- Weapon Mastery is applied by CAT. Topple asks for its save with no source item; Stasis v3 marks "hit by a Topple weapon" instead.
- Summons: dnd5e's own Summon activity with CAT's summon generic (`flags.cat.macros.summon/move = [{source: 'cat', identifier: 'summon'}]`). Ring of the Sunken King uses this; familiars come from Chris's Premades 2's Find Familiar.
- Chris's Premades 2 covers Life Bond, Hold Person / Monster's repeat save, Font of Inspiration, Fire Shield, Vitality of the Tree (with its Rage), Uncanny Dodge, 2024 Warding Flare, Martial Arts / Empowered Strikes / Deflect Attacks and Wild Shape; ours retire on v14.

## Conventions for v14 copies
- Files live next to the v13 ones in a `v14/` folder; the registry entry gets `v14: {file, target?}` (`target` = CAT `{event, pass, priority}` for embedded entries), or `v14: {retired: 'why'}` when Chris's Premades 2 does it.
- Wrap every macro body in `return await (async () => {...})();` so it never re-declares a scope name (`actor`, `item`, `token`, `document`...). Easiest: write the macro as a function in the installer and store `'return await (' + fn.toString() + ')();'`.
- CAT helpers take TokenDocuments; `workflow.token` / `workflow.targets` / `canvas.tokens.placeables` are placeables. Convert at the boundary.
- Effects created by macros: `effectUtils.createEffects(actor, [data])`, `flags.cat.identifier`, `flags.cat.embeddedMacros`, `system.changes`, `duration: {value, units: 'seconds'|'rounds'}`. Find them with `actorUtils.getEffectByIdentifier`. "Until the start/end of the source's turn" still goes in `flags.dae.specialDuration` (DAE converts it).
- Name primed/helper effects differently from the item that makes them (CAT fires one document name per event).
- Remove our v13 copy from `flags.chris-premades` when writing the v14 one (`dropOld` in each installer clears item and activity macros by name).
- Damage: add with `bonusDamage` at `actorDamageRollBonuses`; replace or retype rolls with `workflow.setDamageRolls` at `actorDamageRoll` / `actorDamageRollBonuses` (`damageRollComplete` is read-only).
- Changing a save: return a Roll from `save / actorBonus` (`MidiQOL.addRollTo` for a bonus). Changing an attack: `workflow.setAttackRoll` at `actorAttackRoll` (900 to come after CPR2's re-rolls).
- A macro shared by several events reads optional scope names with `typeof x !== 'undefined'` (`skillId` vs `checkId`, `workflow` in a rest event).
- Cross-automation signals: Counterspell v14 calls `Hooks.callAll('nixCounterspelled', workflow)` after a counter (Shift Spell listens). Subtle Spell still sets `workflow.nixSubtle` before Counterspell's priority 10.
